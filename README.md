## 👨‍💻 About Me

I'm **Jorge Aparicio**, a **Software Engineering student** interested in the intersection between software, data and the web.

I enjoy understanding how a problem works before thinking about how to solve it. That mindset has led me to explore different areas of technology — from **database design and data analysis** to **web development, backend services and APIs**.

Rather than focusing on one single technology, I like understanding **how different pieces fit together** to create useful and maintainable solutions.

### 🔎 What drives me

I'm especially interested in projects where technology can:

* 📊 Transform data into meaningful information.
* 🌐 Simplify processes through web solutions.
* 🔌 Connect systems through APIs and backend services.
* 🗄️ Organize information through well-designed databases.
* 🧩 Solve practical problems through software engineering.
